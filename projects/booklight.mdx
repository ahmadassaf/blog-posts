## Booklight

> **Status**: The [repo](https://github.com/ahmadassaf/booklight) is alive (around 110 stars, last pushed August 2026), but the extension still targets Chrome's Manifest V2, which Chrome has been phasing out; it would need a Manifest V3 migration to run on current Chrome.

I got fed up wasting my time navigating through a maze of bookmark folders to keep them arranged. So if you are:
- Obsessed with organization
- Sitting on hundreds or thousands of folders in your bookmarks
- Keen to keep things tidy, with every page in its "perfect" place

then you've come to the right place. **Booklight** is a clean Chrome Extension to ease the way of adding a bookmark.

- To launch, press `ctrl/Control + b`
- To enable bookmarks search mode hit `space` after booklight is launched

[Download from Github](https://github.com/ahmadassaf/booklight)
[Watch YouTube Video](https://www.youtube.com/watch?v=fxqaToLRLNo)

## Features

- Filter bookmarks based on manual entry
- Show the path of the current selected folder
- Navigate easily through the folders tree using keyboard
- Bookmark directly when you find your target
- Switch to urls search mode
- Launch urls in the current or a new tab
- Fuzzy search for filtering on both folders and urls
- Clean current URL before bookmarking (sometimes the url is polluted with query strings e.g `?source= ...` for various tracking information). To clean the url from those, hit `ctrl+alt+x`.

## Bookmark Search & Launch

Booklight can search across your bookmarks, **and it is fast**. I have around 20,000 bookmarks, and through lazy loading and fuzzy search you can search and launch any of them from wherever you are browsing.
To switch to the url search mode just hit `space`; you will see the `|` symbol appear in the input box to indicate you are now searching urls.
To launch a url in the current window, hit `enter`; to open it in a new tab, hit `ctrl/control + enter`.

## Booklight Performance

I currently have over 1,000 folders and 20,000 bookmarked urls, so performance was a real constraint rather than an afterthought. The two tricks that matter: minimizing DOM manipulation, and lazy-loading url results in small batches (15 at a time by default) instead of rendering the whole result set. The batch size is tweakable, and the same mechanism drives both searching and filtering. The implementation lives in the extension's lazyloader in [the repo](https://github.com/ahmadassaf/booklight) if you want the details.
